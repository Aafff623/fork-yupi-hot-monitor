# Domain Map

## 产品目标

把多平台内容流转化为可订阅、可解释热点信号的监控系统。

## 代码所有权

| 范围 | 职责 |
|---|---|
| `server/` | Express、Prisma 与采集任务 |
| `client/` | React 仪表盘 |
| `skills/hot-monitor/` | 独立技能 |
| `docs/` | 运维说明 |

## 主链路

`关键词 → 账号检测/查询扩展 → 多源并行采集 → 去重与时效过滤 → AI 审核 → 通知`

## 不变量

- 身份标识使用 `threetwoa`；上游名称仅用于来源说明。
- 业务入口不得绕过权限、校验、协议或持久化边界。
- 外部服务失败必须有显式错误或保守降级，不能伪造成功。
- 配置与凭据分离，仓库只保留安全示例。

## 已知风险

平台抓取受限流和页面结构影响；AI 不可用时必须保守降级；定时与手动任务可能并发；邮件只用于高优先级信号。
